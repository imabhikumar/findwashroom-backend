# FindWashroom Backend - Setup Guide

## Prerequisites
- PHP 8.3+
- Composer
- Node.js 18+
- MySQL 8.0+ (or SQLite for development)
- Git

## Initial Setup

### 1. Clone Repository & Install Dependencies
```bash
git clone <repository-url>
cd find-backend
composer install
npm install
```

### 2. Environment Configuration
```bash
# Copy example environment file
cp .env.example .env

# Generate application key
php artisan key:generate
```

### 3. Configure Database Connection
Edit `.env` file:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=findwashroom
DB_USERNAME=root
DB_PASSWORD=

# For SQLite (development):
# DB_CONNECTION=sqlite
# DB_DATABASE=database/database.sqlite
```

### 4. Run Database Migrations
```bash
php artisan migrate --force
php artisan db:seed
```

### 5. Configure Third-Party Services

#### Razorpay (Payments)
Add to `.env`:
```env
RAZORPAY_KEY_ID=your_key_id
RAZORPAY_KEY_SECRET=your_key_secret
```

#### Mail Service (Optional)
```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=465
MAIL_USERNAME=your_username
MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=ssl
```

### 6. Build Frontend Assets
```bash
npm run build   # Production
npm run dev     # Development (watch mode)
```

### 7. Start Development Server
**Option A - Individual terminals:**
```bash
# Terminal 1: Laravel server
php artisan serve

# Terminal 2: Queue listener
php artisan queue:listen --tries=1 --timeout=0

# Terminal 3: Logs viewer
php artisan pail --timeout=0

# Terminal 4: Vite dev server
npm run dev
```

**Option B - Concurrent (recommended):**
```bash
composer run dev
```
This runs all services simultaneously using concurrently.

## Database Management

### Create New Migration
```bash
php artisan make:migration <name>
# Example: php artisan make:migration create_products_table
```

### Rollback Migrations
```bash
php artisan migrate:rollback    # Last batch
php artisan migrate:reset       # All
php artisan migrate:refresh     # Reset + Migrate
```

### Seed Database
```bash
php artisan db:seed
php artisan db:seed --class=UserSeeder
```

## Common Issues & Solutions

### 1. Port 8000 Already in Use
```bash
# Use different port
php artisan serve --port=8001
```

### 2. Database Connection Error
- Verify `.env` database credentials
- Ensure MySQL is running: `mysql -u root -p`
- For SQLite: ensure `database/database.sqlite` exists

### 3. Migration Fails
```bash
# Check migration status
php artisan migrate:status

# Rollback and try again
php artisan migrate:reset
php artisan migrate
```

### 4. Composer Autoload Issue
```bash
composer dump-autoload
```

### 5. Permission Issues on Linux/Mac
```bash
chmod -R 777 storage/
chmod -R 777 bootstrap/cache/
```
